# proyecto1

version V1.1

Sistema de Reparación Telefónica (SISATT / COMACOTA) — Backend Node.js + Express + SQL Server y Frontend Vue 3 + Vite.

- **Documentación de continuación:** ver [`AGENTS.md`](./AGENTS.md) (arquitectura, deploy, módulos, convenciones y pendientes).
- **Backend:** ver [`backend/README.md`](./backend/README.md) (endpoints, tablas y variables de entorno).
- **Frontend:** ver [`frontend/README.md`](./frontend/README.md).

## Inicio rápido

```bash
# Backend
cd backend && npm install && npm run dev

# Frontend
cd frontend && npm install && npm run dev

# Deploy (Docker Compose)
docker compose build && docker compose up -d
```
